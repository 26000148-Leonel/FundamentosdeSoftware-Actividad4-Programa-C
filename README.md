# Conversor de Monedas
## En este respositorio estaremos adjuntando el codigo sobre un programa que permite convertir el valor de monetario a quetzales, dolares, euros, etc. Este programa fue realizado en C desde nuestra maquina virtual
### Las tecnologias a instalar para poder realizar este conversor de el valor monetario de una cantidad, deberemos de instalar Visual Studio Code y deberemos de instalar el C, ademas deberemos de instalar Git y crear una cuenta en GitHub o ingresar a una cuenta ya creada
### Pasos para su ejecucion
### 1) Instalar el compilador de C (GCC) Ejemplo: sudo apt install build-essential
### 2) Crear la carpeta del proyecto
### 3) Crear el archivo del programa en C
### 4) Compilar el programa Ejemplo: gcc conversor.c -o conversor
### 5) Ejecutar el programa Ejemplo: ./conversor
### 6) Crear un Repositorio en GitHub
### 7) Ir a la Carpeta donde se encuentra el Programa
### 8) Inicializar repositorio Git Ejemplo: git init
### 9) Agregar los archivos Ejemplo: git add .
### 10) Crear el commit Ejemplo: git commit -m "First Commit"
### 11) Conectar el repositorio con GitHub Ejemplo: git remote add origin https://github.com/USUARIO/NOMBRE_REPOSITORIO.git
### 12) Subir los archivos a GitHub Ejemplo: git push -u origin main
### 13) Abrir el repositorio, validar que este cargados todos los archivos.
